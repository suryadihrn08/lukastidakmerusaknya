# Lukastidakmerusaknyatoto
Static website siap untuk GitHub Pages.

## Deploy
1. Buat repository GitHub baru bernama `lukastidakmerusaknyatoto`.
2. Upload seluruh isi folder ini ke branch `main` (pastikan `index.html` ada di root repository).
3. Buka Settings > Pages.
4. Pada Build and deployment, pilih Deploy from a branch.
5. Pilih branch `main` dan folder `/ (root)`, lalu Save.
